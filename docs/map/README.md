# Map

Answers two questions before a change: **what else moves if I touch this**
(open the territory, follow `## Blast radius`) and **what is this code derived
from** (`## Governing decisions`, `## Reference behaviour`).

## Coverage

Empty. The package has no scroll code yet, so an absent note is the correct
state, not a backlog item. **A territory note is owed when its first slice
lands**; an invariant note when a fact is found to hold in more than one
territory.

## Conventions

- Notes follow the `grill-map` templates; empty sections stay, with `**None.**`.
- Territories overlap. Code is named by `file — symbol`, never line numbers.
- Plain relative markdown links, not `[[wikilinks]]`.
